# Simple Interest Calculator

This project is a simple interest calculator implemented using Bash.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

- Principal amount
- Annual rate of interest
- Time period in years

## Output

The calculator displays the simple interest based on the values entered by the user.

## How to Run

Run the `simple-interest.sh` script in a terminal and enter the principal amount, annual rate of interest, and time period when prompted.
